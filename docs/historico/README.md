# Histórico completo da exploração

Material de consulta: **todas** as tentativas da POC, incluindo becos sem saída, sweeps reprovados e
entregas superadas. O README da raiz conta só a linha vencedora ([`bench/CAMINHO.md`](../../bench/CAMINHO.md)).

| documento | o que é |
|---|---|
| [`bench/REPORT.md`](../../bench/REPORT.md) (+ `REPORT.html`) | Relatório vivo da linha LFM3 (F0→P2), com todas as fases, inclusive as descartadas (F2 injeção de conhecimento/task-vector/K2V, LiteRT, sweeps, v5 do RLVR). |
| [`HISTORICO.md`](HISTORICO.md) | Mapa cronológico dos experimentos da fase LFM2.5 (18 pastas): pergunta, veredito, quem superou quem. |
| [`AS_IS.md`](AS_IS.md) | Handoff de engenharia da entrega LFM2.5 anterior (pipeline híbrido 1.2B), com o registro de decisões daquela fase. |
| [`README_LFM25.md`](README_LFM25.md) | README raiz da entrega LFM2.5 (reprodução do 1.2B tool, mapa de pastas, artefatos removidos na limpeza). |
| [`relatorio_poc.html`](relatorio_poc.html) | Apresentação (storytelling) da fase LFM2.5. |

Os `RESULTS.md`/`README.md` de cada pasta de experimento (`bench/lfm3_*`, `tools_*`, `sft_*`,
`retrieval*`, `classifier/` etc.) seguem sendo a fonte primária de cada número. Diretórios removidos na
limpeza vivem na tag `poc-completa-pre-limpeza`.
